# ToonMate 🐾⏰

> **Your Cartoon Schedule Companion & Virtual Personal Assistant**

ToonMate is a modern, responsive schedule and reminder application where an animated cartoon character acts as your virtual assistant. Instead of boring static notifications, your companion lives inside the app, vocalizes upcoming schedules, speaks reminders, reacts to completed/missed tasks, and makes productivity fun.

---

## ✨ Features

- 🎭 **6 Original Cartoon Characters**: Bambu (Panda), Sparky (Robot), Mochi (Cat), Barkley (Dog), Rusty (Fox), and Cosmo (Superhero).
- 🌈 **9 Animated States**: Idle, Happy, Sleeping, Talking, Excited, Worried, Celebrating, Sad, and Thinking.
- 🗣️ **Text-to-Speech & Voice**: Web Speech API integration speaks reminders, schedule queries, and celebrations aloud.
- 💬 **Interactive Chat**: Ask *“What do I have today?”*, *“When is my next class?”*, *“What should I do next?”*, or ask for jokes and motivation.
- ⏰ **Smart Reminders**: Real-time ticker with tiered advance warnings (30m, 10m, start time) and floating alert toasts.
- 📅 **Today's Timeline & Calendar**: Connected chronological timeline plus Month, Week, and Day calendar views.
- 🏆 **Gamification**: Daily & weekly completion %, XP levels, streaks, and unlockable achievement badges with confetti.
- 👗 **Character Studio**: Rename character, equip accessories (Glasses, Hat, Bowtie, Cape, Headset, Scarf), and choose habitats & personalities.
- 🌙 **Daily Summary**: Evening review with vocalized mascot commentary and performance stats.
- 📱 **Responsive Design**: Tailored for desktop, tablet, and mobile with bottom navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/chiddarth/toonmate.git

# Navigate to project folder
cd toonmate

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Building for Production

```bash
npm run build
npm run preview
```
